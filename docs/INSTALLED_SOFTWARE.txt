2. UBUNTU (inside WSL)
----------------------
All of this disappears with:  wsl --unregister Ubuntu
To remove pieces individually instead:

  git, make, iperf3, golang-go (Go 1.26) and their build tools (gcc, cpp, pkgconf)
      Remove: sudo apt remove --purge git make iperf3 golang-go && sudo apt autoremove --purge
  uv 0.13.x (Python tool) ............ ~/.local/bin/uv and ~/.local/bin/uvx
      Remove: rm ~/.local/bin/uv ~/.local/bin/uvx && rm -rf ~/.cache/uv ~/.local/share/uv
  ~/RootLine ......................... project (Ubuntu copy), including data/ and bin/
      Remove: rm -rf ~/RootLine
  ~/opentelemetry-demo ............... OpenTelemetry Demo 3.1.0
      Remove: rm -rf ~/opentelemetry-demo
  ~/.ssh/id_ed25519 (planned) ........ SSH key for logging in to the boards
      Remove: rm ~/.ssh/id_ed25519 ~/.ssh/id_ed25519.pub
  Go module cache .................... ~/go
      Remove: rm -rf ~/go
  Claude Code ........................ ~/.local/bin/claude, settings in ~/.claude
      Remove: rm -rf ~/.local/bin/claude ~/.local/share/claude ~/.claude
  Ollama (planned) ................... runs Qwen3 8B and Gemma 3 4B locally
      Remove: sudo systemctl disable --now ollama && sudo rm /usr/local/bin/ollama
              /etc/systemd/system/ollama.service && sudo rm -rf /usr/share/ollama
              && sudo userdel ollama
  Ollama models (planned) ............ qwen3:8b (5.2 GB), gemma3:4b (3.4 GB)
      Remove: ollama rm qwen3:8b gemma3:4b   (or delete them with Ollama itself)
